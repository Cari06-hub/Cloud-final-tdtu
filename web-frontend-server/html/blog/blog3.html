AWS EC2 là gì?

Từ máy ảo Ubuntu và Public IP đến các bước triển khai MyMiniCloud bằng Docker.

MyMiniCloud • Bài viết kiến thức Cloud Computing

1. Amazon EC2 là gì?

Amazon Elastic Compute Cloud (EC2) cung cấp máy chủ ảo có thể cấu hình CPU, RAM, ổ đĩa và hệ điều hành. Một máy chủ ảo EC2 được gọi là instance, có thể dùng để chạy website, API và nhiều dịch vụ backend.

Với bài MyMiniCloud, nhóm dùng EC2 Ubuntu làm môi trường triển khai toàn bộ các container sau khi kiểm thử local.

2. EC2 Ubuntu và kết nối SSH

Khi tạo instance Ubuntu, người quản trị chọn image hệ điều hành, loại máy, khóa SSH và cấu hình mạng. Sau đó dùng SSH để đăng nhập, cài Docker Engine và Docker Compose.

ssh -i <key.pem> ubuntu@<PUBLIC_IP>
docker compose up -d --build

Ví dụ trên chỉ mô tả quy trình; phải thay khóa và Public IP bằng giá trị thật do nhóm triển khai cung cấp.

3. Public IP và Security Group

Public IP là địa chỉ để truy cập instance từ Internet khi định tuyến và quy tắc bảo mật cho phép. Security Group đóng vai trò tường lửa cấp instance, chỉ cho phép lưu lượng trên những port cần thiết.

PortMục đíchGợi ý
22SSHGiới hạn IP quản trị
80Gateway webMở cho người dùng demo
3306MariaDBKhông mở Internet

4. Triển khai MyMiniCloud qua Docker Compose

  1. Chuyển mã nguồn và file cấu hình lên EC2 bằng Git hoặc phương thức bàn giao đã thống nhất.
  2. Tạo file .env riêng trên máy EC2, không đưa mật khẩu lên Git.
  3. Build và khởi chạy các service với docker compose up -d --build.
  4. Dùng docker compose ps và log để kiểm tra container.
  5. Truy cập http://<PUBLIC_IP>/ và các API qua Gateway để demo.

5. EC2 liên quan gì đến các thành viên trong nhóm?

Thành viên 1 chuẩn bị Web Nginx, Flask và MariaDB; các thành viên còn lại chuẩn bị dịch vụ xác thực, lưu trữ, giám sát và Gateway. Thành viên 3 phụ trách ghép Compose và triển khai EC2, còn mỗi người hỗ trợ xử lý phần mình nếu có lỗi tích hợp.

Lưu ý về chi phí: EC2, ổ đĩa và lưu lượng có thể phát sinh phí. Nhóm nên kiểm tra cấu hình và dừng tài nguyên khi không dùng.
