Docker là gì?

Tìm hiểu cách Docker đóng gói, chạy và kết nối các dịch vụ của MyMiniCloud.

MyMiniCloud • Bài viết kiến thức Cloud Computing

1. Docker giải quyết vấn đề gì?

Khi triển khai ứng dụng trên nhiều máy, phiên bản thư viện, cấu hình hệ điều hành hoặc lệnh khởi động khác nhau có thể gây lỗi. Docker đóng gói ứng dụng cùng các phụ thuộc cần thiết vào một image, sau đó khởi chạy image thành container.

Container tách biệt tiến trình và môi trường chạy, nhưng vẫn chia sẻ nhân hệ điều hành của máy chủ. Điều này giúp việc phát triển, kiểm thử và triển khai nhất quán hơn.

2. Image, container và Dockerfile

Thành phầnVai trò
DockerfileCác bước hướng dẫn để tạo image.
ImageGói ứng dụng và cấu hình dùng làm mẫu khởi chạy.
ContainerPhiên bản chạy thực tế của một image.
VolumeLưu trữ dữ liệu không phụ thuộc vòng đời container.
Ví dụ: Web Nginx và Flask dùng image xây riêng; MariaDB có thể dùng image chính thức và volume để lưu dữ liệu.

3. Docker Compose và mạng nội bộ

Docker Compose khai báo nhiều dịch vụ trong một file YAML, bao gồm image, port, biến môi trường, volume và network. Trong MyMiniCloud, các dịch vụ kết nối chung vào mạng cloud-net.

Trong cùng Docker Network, Flask truy cập database theo tên relational-database-server và cổng nội bộ 3306. Không dùng localhost vì nó trỏ về chính container Flask.

docker compose up -d --build
docker compose ps

4. Docker được ứng dụng trong MyMiniCloud thế nào?

  1. Nginx phục vụ trang chủ và ba bài blog HTML.
  2. Flask cung cấp các API /hello, /student và /students-db.
  3. MariaDB lưu dữ liệu quan hệ và cho phép Flask truy vấn qua mạng Docker.
  4. Khi tích hợp, Gateway định tuyến request; Prometheus theo dõi trạng thái các service.

Nhờ mô hình này, nhóm có thể phát triển độc lập từng phần và ghép thành hệ thống bằng Docker Compose.

5. Những lợi ích và lưu ý

  • Nhất quán: image giúp giảm sai khác giữa máy cá nhân và máy chủ EC2.
  • Dễ tích hợp: các container trao đổi qua tên service.
  • Dễ quản lý: có thể xem log và khởi động lại từng dịch vụ.
Lưu ý: Docker không tự động bảo mật ứng dụng. Mật khẩu, cổng mạng và quyền truy cập vẫn cần cấu hình cẩn thận.
