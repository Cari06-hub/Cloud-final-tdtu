Cloud Computing cơ bản

Hiểu mô hình cấp phát tài nguyên theo nhu cầu, khả năng co giãn và các lớp dịch vụ Cloud.

MyMiniCloud • Bài viết kiến thức Cloud Computing

1. Cloud Computing là gì?

Cloud Computing là cách cung cấp các tài nguyên tính toán như máy chủ, lưu trữ, mạng và cơ sở dữ liệu qua Internet. Thay vì đầu tư hạ tầng vật lý ngay từ đầu, người dùng có thể thuê tài nguyên và quản lý chúng qua nền tảng Cloud.

Những tài nguyên này vẫn chạy trên các máy chủ thật trong trung tâm dữ liệu; điểm khác biệt nằm ở khả năng cấp phát, quản trị và mở rộng linh hoạt.

2. Tài nguyên theo nhu cầu (On-demand)

Với cơ chế on-demand self-service, người dùng có thể tạo máy chủ ảo khi cần mà không phải chờ lắp đặt phần cứng. Ví dụ, một nhóm có thể tạo EC2 Ubuntu để thử hệ thống MyMiniCloud, dừng tài nguyên khi không dùng và kiểm soát chi phí.

Phân biệt: on-demand là khả năng cấp phát khi cần; tính phí cụ thể tùy loại tài nguyên, thời gian sử dụng và chính sách nhà cung cấp.

3. Elasticity và scalability

Scalability là khả năng tăng năng lực xử lý; có thể nâng cấu hình một máy (scale up) hoặc thêm máy (scale out). Elasticity nhấn mạnh khả năng tăng giảm tài nguyên theo nhu cầu thực tế.

Trong MyMiniCloud, bài Round Robin dùng hai Web Server để minh họa phân phối yêu cầu. Đây là mô hình học tập về cân bằng tải, chưa phải hệ thống tự động mở rộng.

4. Ba mô hình dịch vụ phổ biến

Mô hìnhNhà cung cấp quản lýVí dụ
IaaSMáy chủ vật lý, mạng, ảo hóaAmazon EC2
PaaSNền tảng chạy và triển khai ứng dụngDịch vụ triển khai ứng dụng quản lý sẵn
SaaSỨng dụng hoàn chỉnhEmail, công cụ văn phòng trực tuyến

Với IaaS, nhóm vẫn cần quản lý hệ điều hành, Docker và cấu hình ứng dụng trên EC2.

5. Liên hệ với bài thực hành MyMiniCloud

  1. Tách Web, API, database và xác thực thành các service độc lập.
  2. Kết nối nội bộ qua Docker Network cloud-net.
  3. Dùng Docker Compose để điều phối môi trường local.
  4. Triển khai lên EC2 Ubuntu và kiểm tra qua Public IP.
